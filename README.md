# Full Stack System - Frontend Design

# Description
A responsive and clean UI built with HTML and CSS focusing on logical design, touchpoints, and mobile accessibility. This acts as the "skin" of the Full Stack application.

# How to Run
1. Clone or download the repository.
2. Open the `index.html` file directly in your web browser.
3. Alternatively, open the folder in VS Code and use the "Live Server" extension.
